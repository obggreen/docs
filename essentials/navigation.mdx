# Authentication

**Secure API access with Bearer tokens**

All RunBlob API requests require authentication using Bearer tokens. Keep your API keys secure and never expose them in client-side code.

</div>

---

## Getting Your API Key

<Steps>
  <Step title="Sign Up">
    Create your RunBlob account at our [dashboard](https://runblob.io/dashboard).
  </Step>
  <Step title="Generate API Key">
    Navigate to the **API Keys** section and generate a new key.

    <Tip>
      Copy your API key immediately - it won't be shown again for security reasons.
    </Tip>
  </Step>
  <Step title="Store Securely">
    Store your API key in environment variables or secure configuration.

    ```bash
    export RUNBLOB_API_KEY="your-api-key-here"
    ```
  </Step>
</Steps>

## Using Your API Key

### Required Headers

Every API request must include these headers:

| Header            | Type     | Required | Description                                           |
| ----------------- | -------- | -------- | ----------------------------------------------------- |
| **Authorization** | `string` | ✅        | Bearer token with your API key: `Bearer YOUR_API_KEY` |
| **Content-Type**  | `string` | ✅        | Always set to `application/json` for POST requests    |

### Example Request

<CodeGroup>

```bash cURL
curl -X POST https://api.runblob.io/api/veo/generate \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "A beautiful sunset over mountains"
  }'
```


```python Python
import requests

headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}

payload = {
    "prompt": "A beautiful sunset over mountains"
}

response = requests.post(
    "https://api.runblob.io/api/veo/generate",
    headers=headers,
    json=payload
)

print(response.json())
```


```javascript JavaScript
const headers = {
  'Authorization': 'Bearer YOUR_API_KEY',
  'Content-Type': 'application/json'
};

const payload = {
  prompt: 'A beautiful sunset over mountains'
};

const response = await fetch('https://api.runblob.io/api/veo/generate', {
  method: 'POST',
  headers: headers,
  body: JSON.stringify(payload)
});

const result = await response.json();
console.log(result);
```

</CodeGroup>

## Security Best Practices

<CardGroup cols={2}>
  <Card title="Server-Side Only" icon="server">
    **Never expose API keys in:**

    - Frontend JavaScript code
    - Mobile app source code
    - Public repositories
    - URL parameters

    Always use server-side requests for API calls.
  </Card>
  <Card title="Environment Variables" icon="file-code">
    **Store API keys in environment variables:**

    - Use `.env` files for local development
    - Configure environment variables in production
    - Never commit keys to version control
  </Card>
  <Card title="Key Rotation" icon="arrows-rotate">
    **Regularly rotate your API keys:**

    - Generate new keys periodically
    - Revoke old keys after updating your applications
    - Monitor key usage in your dashboard
  </Card>
  <Card title="Monitor Usage" icon="chart-line">
    **Track your API usage:**

    - Monitor request patterns in your dashboard
    - Set up alerts for unusual activity
    - Review logs regularly
  </Card>
</CardGroup>

## Error Responses

### Invalid API Key

```json
{
  "error": "Unauthorized",
  "message": "Invalid API key"
}
```

### Missing Authorization Header

```json
{
  "error": "Unauthorized", 
  "message": "Authorization header required"
}
```

### Malformed Authorization Header

```json
{
  "error": "Unauthorized",
  "message": "Invalid authorization format. Use: Bearer YOUR_API_KEY"
}
```
