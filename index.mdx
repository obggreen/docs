## Example: Generate Your First Video

Choose your preferred language and start generating:

<CodeGroup>

```python Python
import requests

response = requests.post(
    "https://api.runblob.com/v1/video/veo31/generate",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    json={
        "prompt": "A serene mountain landscape at sunset",
        "duration": 5
    }
)

result = response.json()
print(f"Task ID: {result['task_id']}")
```


```javascript JavaScript
const response = await fetch('https://api.runblob.com/v1/video/veo31/generate', {
  method: 'POST',
  headers: { 'Authorization': 'Bearer YOUR_API_KEY' },
  body: JSON.stringify({
    prompt: 'A serene mountain landscape at sunset',
    duration: 5
  })
});

const result = await response.json();
console.log(`Task ID: ${result.task_id}`);
```


```bash cURL
curl -X POST https://api.runblob.com/v1/video/veo31/generate \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"prompt": "A serene mountain landscape at sunset", "duration": 5}'
```
