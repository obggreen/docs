## Model Comparison

| Feature | Google Veo3 | Kling AI |
|---------|-------------|----------|
| Text-to-Video | Yes | Yes (most versions) |
| Image-to-Video | Yes | Yes |
| Frame-to-Frame | Yes | No |
| Reference Images | Yes | No |
| Negative Prompts | No | Yes (1.6, 2.1) |
| CFG Scale | No | Yes (1.6 only) |
| Generation Time | 1-10 min | 2-5 min |
| Best For | High quality, complex scenes | Speed, creative control |
