## POST /v1/kling/o1-video/generate

Creates a video generation task from text description or images using Kling O1 Video model.

<ParamField path="prompt" type="string" required>
  Text description of the video (1-2500 characters)
</ParamField>

<ParamField path="duration" type="string" required>
  Video duration in seconds
  - **Text-to-video:** `"5"` or `"10"`
  - **Image-to-video:** `"3"`, `"4"`, `"5"`, `"6"`, `"7"`, `"8"`, `"9"`, `"10"`
</ParamField>

<ParamField path="aspect_ratio" type="string" required>
  Video aspect ratio: `"16:9"` (landscape), `"9:16"` (portrait), `"1:1"` (square)
</ParamField>

<ParamField path="images_base64" type="array">
  Array of base64-encoded images (max 5, JPEG/PNG/WebP)
</ParamField>

<ParamField path="images_urls" type="array">
  Array of image URLs (max 5, alternative to `images_base64`)
</ParamField>

<ParamField path="keep_original_sound" type="boolean" default="true">
  Keep original audio from images
</ParamField>

<ParamField path="callback_url" type="string">
  Webhook URL for completion notifications
</ParamField>

<Warning>
  Provide either `images_base64` OR `images_urls`, not both. Duration options `"3"`, `"4"`, `"6"`, `"7"`, `"8"`, `"9"` are only available for image-to-video.
</Warning>

<CodeGroup>

```bash Text-to-Video
curl -X POST https://platform.runblob.io/v1/kling/o1-video/generate -H "Authorization: Bearer YOUR_API_KEY" -H "Content-Type: application/json" -d '{
  "prompt": "A cinematic shot of a cat walking in slow motion",
  "duration": "5",
  "aspect_ratio": "16:9"
}'
```

```bash Image-to-Video (URLs)
curl -X POST https://platform.runblob.io/v1/kling/o1-video/generate -H "Authorization: Bearer YOUR_API_KEY" -H "Content-Type: application/json" -d '{
  "prompt": "Animate the photo, make the person smile",
  "duration": "5",
  "aspect_ratio": "16:9",
  "images_urls": [
    "https://example.com/photo1.jpg",
    "https://example.com/photo2.jpg"
  ]
}'
```

```bash Multiple Images (Base64)
curl -X POST https://platform.runblob.io/v1/kling/o1-video/generate -H "Authorization: Bearer YOUR_API_KEY" -H "Content-Type: application/json" -d '{
  "prompt": "Create a story from these moments",
  "duration": "10",
  "aspect_ratio": "16:9",
  "keep_original_sound": true,
  "callback_url": "https://your-app.com/webhooks/kling",
  "images_base64": [
    "data:image/jpeg;base64,/9j/4AAQSkZJRg...",
    "data:image/jpeg;base64,/9j/4AAQSkZJRg...",
    "data:image/jpeg;base64,/9j/4AAQSkZJRg..."
  ]
}'
```

<Note>
  Video generation typically takes 1-10 minutes. Use the `generation_id` to [check status](/api-reference/kling/video-status) or set up [webhooks](/api-reference/kling/video-webhooks) for notifications.
  
  **Check status:** `GET /v1/kling/o1-video/generations/{generation_id}`
</Note>

## Generation Modes

The API supports **2 generation modes**:

### 1. Text-to-Video
Generate video from text prompt only (no images).

- **Duration:** `"5"` or `"10"` seconds
- No image parameters required

```json
{
  "prompt": "Epic cinematic scene of a dragon flying",
  "duration": "10",
  "aspect_ratio": "16:9"
}
```

### 2. Image-to-Video
Animate up to 5 images with text prompt.

- **Duration:** `"3"`, `"4"`, `"5"`, `"6"`, `"7"`, `"8"`, `"9"`, `"10"` seconds
- Formats: JPEG, PNG, WEBP
- Max size: 10 MB per image
- Max images: 5

```json
{
  "prompt": "Bring these photos to life with smooth animation",
  "images_urls": [
    "https://example.com/photo1.jpg",
    "https://example.com/photo2.jpg"
  ],
  "duration": "8",
  "aspect_ratio": "16:9"
}
```

## Multi-Image Support

<AccordionGroup>
  <Accordion icon="images" title="How It Works">
    - Images are processed in order
    - Each image is referenced internally as `@Image1`, `@Image2`, etc.
    - All images are combined into the final video
    - The AI uses the prompt to guide the animation
  </Accordion>
  
  <Accordion icon="check" title="Image Requirements">
    - **Max size:** 10 MB per image
    - **Formats:** JPEG, PNG, WebP
    - **Max total:** 5 images per request
    - Either URLs or Base64 (not both)
  </Accordion>
  
  <Accordion icon="clock" title="Duration Options">
    **Text-to-video:**
    - 5 seconds
    - 10 seconds
    
    **Image-to-video:**
    - 3, 4, 5, 6, 7, 8, 9, or 10 seconds
  </Accordion>
</AccordionGroup>

## Aspect Ratios

| Aspect Ratio | Use Case | Resolution |
|--------------|----------|------------|
| 16:9 | Landscape, YouTube, widescreen | Optimized for horizontal displays |
| 9:16 | Portrait, TikTok, Instagram Reels | Optimized for vertical/mobile |
| 1:1 | Square, Instagram feed | Balanced format |

## Error Responses

**400 Bad Request:**
```json
{
  "detail": "Duration 3 seconds is only available for image-to-video generation"
}
```

**402 Payment Required:**
```json
{
  "detail": "INSUFFICIENT_CREDITS"
}
```

**422 Validation Error:**
```json
{
  "detail": "Maximum 5 images allowed"
}
```
