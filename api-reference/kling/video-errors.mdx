## Error Categories

<Tabs>
  <Tab title="User Errors">
    Issues caused by invalid requests or insufficient resources.
    
    <AccordionGroup>
      <Accordion icon="credit-card" title="INSUFFICIENT_CREDITS">
        **Description:** Not enough credits to complete the request
        
        **Solution:** Add more credits to your account
        
        ```json
        {
          "detail": "INSUFFICIENT_CREDITS"
        }
        ```
      </Accordion>
      
      <Accordion icon="question-circle" title="Generation Not Found">
        **Description:** Generation with specified ID does not exist
        
        **Solution:** Verify the generation ID is correct
        
        ```json
        {
          "detail": "Generation not found"
        }
        ```
      </Accordion>
      
      <Accordion icon="exclamation-triangle" title="Invalid Duration">
        **Description:** Duration not allowed for selected generation mode
        
        **Solution:** Use `"5"` or `"10"` for text-to-video, or provide images for custom durations
        
        ```json
        {
          "detail": "Duration 3 seconds is only available for image-to-video generation"
        }
        ```
      </Accordion>
      
      <Accordion icon="image" title="INVALID_IMAGE">
        **Description:** One or more input images are not valid
        
        **Solution:** Ensure you're uploading valid JPEG, PNG, or WEBP files under 10MB
        
        ```json
        {
          "status": "failed",
          "message": "INVALID_IMAGE"
        }
        ```
      </Accordion>
      
      <Accordion icon="link-slash" title="IMAGE_INACCESSIBLE">
        **Description:** One or more image URLs returned 404 or 403
        
        **Solution:** Verify all image URLs are publicly accessible
        
        ```json
        {
          "status": "failed",
          "message": "IMAGE_INACCESSIBLE"
        }
        ```
      </Accordion>
      
      <Accordion icon="hashtag" title="Too Many Images">
        **Description:** More than 5 images provided
        
        **Solution:** Limit images to maximum of 5 per request
        
        ```json
        {
          "detail": "Maximum 5 images allowed"
        }
        ```
      </Accordion>
    </AccordionGroup>
  </Tab>
  
  <Tab title="Content Errors">
    Issues with prompt content or uploaded images.
    
    <AccordionGroup>
      <Accordion icon="shield-exclamation" title="CONTENT_POLICY_VIOLATION">
        **Description:** Content violates usage policies
        
        **Solution:** Modify your prompt to comply with content guidelines
        
        ```json
        {
          "status": "failed",
          "message": "CONTENT_POLICY_VIOLATION"
        }
        ```
      </Accordion>
    </AccordionGroup>
  </Tab>
  
  <Tab title="System Errors">
    Technical issues on RunBlob or Kling's side.
    
    <AccordionGroup>
      <Accordion icon="clock" title="TIMEOUT">
        **Description:** Task exceeded maximum processing time (15 minutes)
        
        **Action:** Credits are automatically refunded
        
        ```json
        {
          "status": "failed",
          "message": "TIMEOUT"
        }
        ```
      </Accordion>
      
      <Accordion icon="ban" title="TASK_FAILED">
        **Description:** Generation failed due to Kling API error
        
        **Action:** Credits are automatically refunded, try again
        
        ```json
        {
          "status": "failed",
          "message": "TASK_FAILED"
        }
        ```
      </Accordion>
      
      <Accordion icon="wrench" title="MAINTENANCE">
        **Description:** Service is temporarily unavailable
        
        **Action:** Wait and retry your request later
        
        ```json
        {
          "status": "failed",
          "message": "MAINTENANCE"
        }
        ```
      </Accordion>
    </AccordionGroup>
  </Tab>
</Tabs>

## Common Issues & Solutions

### Issue: "Duration X seconds is only available for image-to-video"

**Cause:** Using duration `"3"`, `"4"`, `"6"`, `"7"`, `"8"`, or `"9"` without providing images.

**Solution:**
- Use `"5"` or `"10"` for text-to-video
- OR provide images to use custom durations

---

### Issue: "IMAGE_INACCESSIBLE" error

**Cause:** The provided `images_urls` returned 404 or 403.

**Solution:**
- Verify URLs are publicly accessible
- Check URLs don't require authentication
- Use `images_base64` instead if URLs are private

---

### Issue: "CONTENT_POLICY_VIOLATION"

**Cause:** AI detected prohibited content (adult, violence, etc.)

**Solution:**
- Review and modify your prompt
- Check input images for inappropriate content
- Avoid explicit or graphic descriptions

---

### Issue: Generation stuck in "pending"

**Cause:** Workers might be overloaded or service experiencing high load.

**Solution:**
- Wait 1-2 minutes, status should change to "processing"
- If stuck for >5 minutes, contact support with `generation_id`

<Warning>
  Always handle errors programmatically using the error codes, not human-readable messages.
</Warning>
