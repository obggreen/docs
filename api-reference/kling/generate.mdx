## POST /v1/kling/generate

Creates a video generation task from text description using Kling AI models.

<ParamField path="prompt" type="string" required>
  Text description of the video (1-2500 characters)
</ParamField>

<ParamField path="negative_prompt" type="string">
  What should NOT be in the video (max 2500 characters)
</ParamField>

<ParamField path="model" type="string" default="kling_2.5_turbo">
  Model to use.
  
  **Available models:**
  - `kling_2.6_motion` (NEW: Motion Control Standard)
  - `kling_2.6_motion_pro` (NEW: Motion Control Pro, 2x price)
  - `kling_2.6` (NEW: Audio-enabled, always Pro quality)
  - `kling_2.5_turbo` (Standard/Turbo)
  - `kling_2.5_turbo_pro` (Professional/Turbo Pro)
  - `kling_2.1` (Standard)
  - `kling_2.1_pro` (Professional)
  - `kling_2.1_master` (Master, no pro mode)
  - `kling_1.6` (Standard)
  - `kling_1.6_pro` (Professional)
</ParamField>

<ParamField path="duration" type="string" default="5">
  Duration: `"5"` (5 seconds) or `"10"` (10 seconds)
</ParamField>

<ParamField path="aspect_ratio" type="string" default="16:9">
  Video aspect ratio: `"16:9"`, `"9:16"`, `"1:1"`
  
  <Info>
    For image-to-video mode, aspect ratio is automatically determined from the input image and should not be specified.
  </Info>
</ParamField>

<ParamField path="cfg_scale" type="number" default="0.5">
  Creativity balance (0.0-1.0). **0.0** = maximum creativity, **1.0** = strict prompt following
</ParamField>

<ParamField path="seed" type="number">
  Reproducibility seed (0-2147483647)
</ParamField>

<ParamField path="callback_url" type="string">
  Webhook URL for completion notifications
</ParamField>

<ParamField path="image_base64" type="string">
  Base64-encoded image for Image-to-Video (JPEG/PNG/WEBP)
</ParamField>

<ParamField path="image_url" type="string">
  URL of image for Image-to-Video
</ParamField>

<ParamField path="reference_video_base64" type="string">
  Base64-encoded reference video for Motion Control (MP4/MOV/WEBP)
  
  **Requirements:**
  - Duration: 3-30 seconds
</ParamField>

<ParamField path="reference_video_url" type="string">
  URL of reference video for Motion Control
</ParamField>

<ParamField path="reference_image_base64" type="string">
  Base64-encoded reference image for Motion Control (JPEG/PNG/WEBP)
</ParamField>

<ParamField path="reference_image_url" type="string">
  URL of reference image for Motion Control
</ParamField>

<Warning>
  **Motion Control requirements:**
  - Both `reference_video` AND `reference_image` are required
  - Video duration must be between 3 and 30 seconds
  - Cannot use both `_base64` and `_url` for the same media type
</Warning>

## Generation Modes

The API supports **3 generation modes**:

### 1. Text-to-Video
Generate video from text prompt only (no images).

**Models:** `kling_1.6`, `kling_2.1_master`, `kling_2.5_turbo`, `kling_2.6`

<Warning>
  `kling_2.1` and `kling_2.1_pro` do NOT support text-to-video. They require an input image.
</Warning>

### 2. Image-to-Video
Animate a single image with text prompt using `image_base64` or `image_url` parameter.

- Formats: JPEG, PNG, WEBP
- Max size: ~10 MB
- Models: `kling_1.6`, `kling_2.1`, `kling_2.1_master`, `kling_2.5_turbo`, `kling_2.6` (and their `_pro` variants)

<Info>
  **Important:** You cannot use both `image_base64` and `image_url` in the same request. For image-to-video mode, aspect ratio is taken from the input image automatically.
</Info>

### 3. Motion Control
Transfer motion and style from a reference video to a reference image.

- **Required:** Both `reference_video` AND `reference_image`
- **Video duration:** 3-30 seconds
- **Video formats:** MP4, MOV, WEBM
- **Image formats:** JPEG, PNG, WEBP
- **Models:** `kling_2.6_motion`, `kling_2.6_motion_pro`
- **Pricing:** Per second (rounded up)
  - Standard: $0.041/sec
  - Pro: $0.082/sec (2x price)
- **Aspect ratio & duration:** Auto-detected from reference video

```json
{
  "prompt": "Apply this motion to the scene",
  "model": "kling_2.6_motion",
  "reference_video_url": "https://example.com/motion.mp4",
  "reference_image_url": "https://example.com/scene.jpg"
}
```


## Models Guide

### Kling 2.6 Motion Control (NEW)
- **Codes:** `kling_2.6_motion`, `kling_2.6_motion_pro`
- **Features:**
  - Motion transfer from reference video
  - Requires reference video (3-30s) + reference image
  - Aspect ratio: Auto-detected from video
  - Duration: Auto-detected from video
  - Negative prompt: No
  - CFG Scale: No
- **Pricing:**
  - Standard: $0.041/sec
  - Pro: $0.082/sec (2x price)
- **Best for:** Transferring motion and style from reference videos

### Kling 2.6 (NEW)
- **Code:** `kling_2.6`
- **Features:**
  - Text-to-video: Yes
  - Image-to-video: Yes
  - Audio support: Yes
  - Always Pro quality
  - Priority processing
  - Negative prompt: No
  - CFG Scale: No
- **Best for:** Highest quality videos with audio support

### Kling 2.5 Turbo (Default)
- **Codes:** `kling_2.5_turbo`, `kling_2.5_turbo_pro`
- **Features:**
  - Text-to-video: Yes
  - Image-to-video: Yes
  - Negative prompt: No
  - CFG Scale: No
- **Best for:** Fastest generation speed

### Kling 2.1 Master
- **Code:** `kling_2.1_master`
- **Features:**
  - Text-to-video: Yes
  - Image-to-video: Yes
  - Negative prompt: Yes
  - CFG Scale: No
- **Best for:** High-quality text-to-video

### Kling 2.1 Pro
- **Codes:** `kling_2.1`, `kling_2.1_pro`
- **Features:**
  - Text-to-video: No (image required)
  - Image-to-video: Yes
  - Negative prompt: Yes
  - CFG Scale: No
- **Best for:** Professional image animation

### Kling 1.6
- **Codes:** `kling_1.6`, `kling_1.6_pro`
- **Features:**
  - Text-to-video: Yes
  - Image-to-video: Yes
  - Negative prompt: Yes
  - CFG Scale: Yes
- **Best for:** Maximum creative control

<Accordion title="CFG Scale Guide">
  **Creativity balance parameter (Kling 1.6 only):**
  
  - **0.0-0.3:** Maximum creativity, AI adds interpretations
  - **0.4-0.6:** Balanced mode (recommended)
  - **0.7-1.0:** Strict prompt following, minimal deviations
</Accordion>
