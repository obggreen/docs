## POST /v1/kling/o1-photo/generate

Creates an image generation task from text description using Kling O1 Photo model.

<ParamField path="prompt" type="string" required>
  Text description of the image (1-2500 characters)
</ParamField>

<ParamField path="images_url" type="array">
  Array of up to 5 image URLs for reference-based generation
</ParamField>

<ParamField path="images_base64" type="array">
  Array of up to 5 base64-encoded images for reference-based generation
</ParamField>

<ParamField path="img_resolution" type="string" default="2k">
  Image resolution: `"1k"` or `"2k"`
</ParamField>

<ParamField path="aspect_ratio" type="string" default="1:1">
  Image aspect ratio. Available options:
  - `"9:16"` - Vertical portrait
  - `"2:3"` - Vertical
  - `"3:4"` - Vertical
  - `"1:1"` - Square (default)
  - `"4:3"` - Horizontal
  - `"3:2"` - Horizontal
  - `"16:9"` - Widescreen
  - `"21:9"` - Ultra-wide
</ParamField>

<ParamField path="callback_url" type="string">
  Webhook URL for completion notifications
</ParamField>

<CodeGroup>

```bash Simple Generation
curl -X POST https://platform.runblob.io/v1/kling/o1-photo/generate \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "A futuristic city with flying cars, neon lights, cyberpunk style",
    "img_resolution": "2k",
    "aspect_ratio": "16:9"
  }'
```


### Response

```json
{
  "generation_id": "photo-550e8400-e29b-41d4-a716",
  "status": "pending",
  "price": "0.0290"
}
```

<ResponseField name="generation_id" type="string">
  UUID of the generation task for status checking
</ResponseField>

<ResponseField name="status" type="string">
  Initial status, always `"pending"`
</ResponseField>

<ResponseField name="price" type="string">
  Amount charged in USD ($0.029 per image)
</ResponseField>

<Note>
  Image generation typically takes 1-2 minutes. Use the `generation_id` to [check status](/api-reference/kling/photo-status) or set up [webhooks](/api-reference/kling/photo-webhooks) for notifications.
  
  **Check status:** `GET /v1/kling/o1-photo/generations/{generation_id}`
</Note>

## Generation Features

<AccordionGroup>
  <Accordion icon="images" title="Reference Images">
    **Use up to 5 input images (total from both sources):**
    - `images_url`: Provide URLs of reference images (HTTPS)
    - `images_base64`: Provide base64-encoded images
    - Supports JPEG, PNG, WEBP formats
    - AI will use them as visual reference for generation
    - Maximum 10 MB per image
  </Accordion>
  
  <Accordion icon="expand" title="Resolution Options">
    **Choose image quality:**
    - **1K:** Faster generation, standard quality
    - **2K:** Higher detail, recommended for most use cases
  </Accordion>
  
  <Accordion icon="crop" title="Aspect Ratios">
    **8 aspect ratio options:**
    - Portrait formats: 9:16, 2:3, 3:4
    - Square: 1:1
    - Landscape formats: 4:3, 3:2, 16:9, 21:9
  </Accordion>
</AccordionGroup>
