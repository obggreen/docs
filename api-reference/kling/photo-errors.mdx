<Info>
  All errors return specific codes in the `message` field for programmatic handling.
</Info>

## Error Categories

<Tabs>
  <Tab title="User Errors">
    Issues caused by invalid requests or insufficient resources.
    
    <AccordionGroup>
      <Accordion icon="credit-card" title="INSUFFICIENT_CREDITS">
        **Description:** Not enough credits to complete the request
        
        **Solution:** Add more credits to your account
        
        ```json
        {
          "success": false,
          "message": "INSUFFICIENT_CREDITS"
        }
        ```
      </Accordion>
      
      <Accordion icon="question-circle" title="GENERATION_NOT_FOUND">
        **Description:** Generation with specified ID does not exist
        
        **Solution:** Verify the generation ID is correct
        
        ```json
        {
          "detail": "Generation not found"
        }
        ```
      </Accordion>
      
      <Accordion icon="exclamation-triangle" title="INVALID_PARAMETERS">
        **Description:** Request parameters are invalid or missing required fields
        
        **Solution:** Check parameter values and types
        
        ```json
        {
          "detail": "Validation error: prompt is required"
        }
        ```
      </Accordion>
      
      <Accordion icon="image" title="INVALID_IMAGE">
        **Description:** One or more input images are not valid
        
        **Solution:** Ensure you're uploading valid JPEG, PNG, or WEBP files
        
        ```json
        {
          "status": "failed",
          "message": "INVALID_IMAGE"
        }
        ```
      </Accordion>
      
      <Accordion icon="link-slash" title="IMAGE_INACCESSIBLE">
        **Description:** One or more image URLs are inaccessible
        
        **Solution:** Verify all image URLs are accessible via HTTPS
        
        ```json
        {
          "status": "failed",
          "message": "IMAGE_INACCESSIBLE"
        }
        ```
      </Accordion>
      
      <Accordion icon="hashtag" title="TOO_MANY_IMAGES">
        **Description:** More than 5 reference images provided
        
        **Solution:** Limit reference images to maximum of 5
        
        ```json
        {
          "detail": "Maximum 5 reference images allowed"
        }
        ```
      </Accordion>
    </AccordionGroup>
  </Tab>
  
  <Tab title="Content Errors">
    Issues with prompt content or uploaded images.
    
    <AccordionGroup>
      <Accordion icon="shield-exclamation" title="CONTENT_POLICY_VIOLATION">
        **Description:** Content violates usage policies
        
        **Solution:** Modify your prompt to comply with content guidelines
        
        ```json
        {
          "status": "failed",
          "message": "CONTENT_POLICY_VIOLATION"
        }
        ```
      </Accordion>
      
      <Accordion icon="shield-slash" title="MODERATION_FAILED">
        **Description:** Content rejected by moderation system
        
        **Solution:** Modify your content to comply with our guidelines
        
        ```json
        {
          "status": "failed",
          "message": "MODERATION_FAILED"
        }
        ```
      </Accordion>
    </AccordionGroup>
  </Tab>
  
  <Tab title="System Errors">
    Technical issues on RunBlob or service provider side.
    
    <AccordionGroup>
      <Accordion icon="clock" title="TIMEOUT">
        **Description:** Task exceeded maximum processing time (15 minutes)
        
        **Action:** Credits are automatically refunded
        
        ```json
        {
          "status": "failed",
          "message": "TIMEOUT"
        }
        ```
      </Accordion>
      
      <Accordion icon="ban" title="TASK_FAILED">
        **Description:** Generation failed due to system error
        
        **Action:** Credits are automatically refunded, try again
        
        ```json
        {
          "status": "failed",
          "message": "TASK_FAILED"
        }
        ```
      </Accordion>
      
      <Accordion icon="wrench" title="SERVICE_UNAVAILABLE">
        **Description:** Service is temporarily unavailable
        
        **Action:** Wait and retry your request later
        
        ```json
        {
          "detail": "Service temporarily unavailable"
        }
        ```
      </Accordion>
    </AccordionGroup>
  </Tab>
</Tabs>

## HTTP Status Code Reference

<ResponseField name="201" type="Created">
  Generation created successfully
</ResponseField>

<ResponseField name="200" type="OK">
  Request successful
</ResponseField>

<ResponseField name="400" type="Bad Request">
  Invalid parameters or request format
</ResponseField>

<ResponseField name="401" type="Unauthorized">
  Invalid or missing API key
</ResponseField>

<ResponseField name="402" type="Payment Required">
  Insufficient credits
</ResponseField>

<ResponseField name="404" type="Not Found">
  Generation not found
</ResponseField>

<ResponseField name="422" type="Validation Error">
  Invalid input format or missing required fields
</ResponseField>

<ResponseField name="500" type="Internal Server Error">
  Server-side error
</ResponseField>

<ResponseField name="503" type="Service Unavailable">
  Service temporarily unavailable
</ResponseField>

<Warning>
  Always handle errors programmatically using the error codes, not human-readable messages.
</Warning>
