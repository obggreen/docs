<Info>
  All errors return specific HTTP status codes and detailed error messages in the `detail` field.
</Info>

## Error Categories

<Tabs>
  <Tab title="User Errors">
    Issues caused by invalid requests or insufficient resources.
    
    <AccordionGroup>
      <Accordion icon="credit-card" title="INSUFFICIENT_CREDITS">
        **HTTP Status:** 402 Payment Required
        
        **Description:** Not enough credits to complete the request
        
        **Solution:** Add more credits to your account
        
        ```json
        {
          "detail": "INSUFFICIENT_CREDITS"
        }
        ```
      </Accordion>
      
      <Accordion icon="question-circle" title="Generation Not Found">
        **HTTP Status:** 404 Not Found
        
        **Description:** Generation with specified ID does not exist
        
        **Solution:** Verify the generation ID is correct
        
        ```json
        {
          "detail": "Generation not found"
        }
        ```
      </Accordion>
      
      <Accordion icon="key" title="Missing Credentials">
        **HTTP Status:** 401 Unauthorized
        
        **Description:** API key not provided or invalid
        
        **Solution:** Include valid Bearer token in Authorization header
        
        ```json
        {
          "detail": "Missing credentials"
        }
        ```
      </Accordion>
      
      <Accordion icon="exclamation-triangle" title="Invalid Parameters">
        **HTTP Status:** 422 Validation Error
        
        **Description:** Request parameters are invalid or missing required fields
        
        **Solution:** Check parameter values and types
        
        ```json
        {
          "detail": "Validation error: prompt is required"
        }
        ```
      </Accordion>
    </AccordionGroup>
  </Tab>
  
  <Tab title="Version Errors">
    Issues specific to model version constraints.
    
    <AccordionGroup>
      <Accordion icon="image" title="Version 2.1 Pro Requires Image">
        **HTTP Status:** 400 Bad Request
        
        **Description:** Version 2.1 Pro only supports image-to-video
        
        **Solution:** Provide `image_base64` or `image_url`, or use a different version
        
        ```json
        {
          "detail": "Version 2.1 Pro is only available for image-to-video. Please provide image_base64 or image_url."
        }
        ```
      </Accordion>
      
      <Accordion icon="ban" title="Both Image Methods Provided">
        **HTTP Status:** 400 Bad Request
        
        **Description:** Cannot use both `image_base64` and `image_url` simultaneously
        
        **Solution:** Choose one image input method
        
        ```json
        {
          "detail": "Cannot provide both image_base64 and image_url. Please use one method."
        }
        ```
      </Accordion>
      
      <Accordion icon="slash" title="Feature Not Supported">
        **HTTP Status:** 400 Bad Request
        
        **Description:** Requested feature not available for selected version
        
        **Solution:** Check model version compatibility table
        
        **Examples:**
        - CFG Scale only works with version 1.6
        - Negative prompts not supported in version 2.5
      </Accordion>
    </AccordionGroup>
  </Tab>
  
  <Tab title="System Errors">
    Technical issues on the server side.
    
    <AccordionGroup>
      <Accordion icon="server" title="Internal Server Error">
        **HTTP Status:** 500 Internal Server Error
        
        **Description:** Unexpected error on the server
        
        **Action:** Retry your request or contact support if the issue persists
        
        ```json
        {
          "detail": "Internal server error"
        }
        ```
      </Accordion>
      
      <Accordion icon="wrench" title="Service Unavailable">
        **HTTP Status:** 503 Service Unavailable
        
        **Description:** Service is temporarily unavailable
        
        **Action:** Wait and retry your request later
      </Accordion>
    </AccordionGroup>
  </Tab>
</Tabs>

## HTTP Status Code Reference

<ResponseField name="201" type="Created">
  Generation created successfully
</ResponseField>

<ResponseField name="200" type="OK">
  Request successful
</ResponseField>

<ResponseField name="400" type="Bad Request">
  Invalid parameters or request format
</ResponseField>

<ResponseField name="401" type="Unauthorized">
  Invalid or missing API key
</ResponseField>

<ResponseField name="402" type="Payment Required">
  Insufficient credits
</ResponseField>

<ResponseField name="404" type="Not Found">
  Generation not found
</ResponseField>

<ResponseField name="422" type="Validation Error">
  Invalid input format or missing required fields
</ResponseField>

<ResponseField name="500" type="Internal Server Error">
  Server-side error
</ResponseField>

<ResponseField name="503" type="Service Unavailable">
  Service temporarily unavailable
</ResponseField>
