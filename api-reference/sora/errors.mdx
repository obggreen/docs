## Error Categories

<Tabs>
  <Tab title="User Errors">
    Issues caused by invalid requests or insufficient resources.
    
    <AccordionGroup>
      <Accordion icon="credit-card" title="INSUFFICIENT_CREDITS">
        **HTTP Status:** 402 Payment Required
        
        **Description:** Not enough credits to complete the request
        
        **Solution:** Add more credits to your account
        
        ```json
        {
          "detail": "INSUFFICIENT_CREDITS"
        }
        ```
      </Accordion>
      
      <Accordion icon="question-circle" title="Generation Not Found">
        **HTTP Status:** 404 Not Found
        
        **Description:** Generation with specified ID does not exist
        
        **Solution:** Verify the generation ID is correct
        
        ```json
        {
          "detail": "Generation not found"
        }
        ```
      </Accordion>
      
      <Accordion icon="key" title="Missing or Invalid Token">
        **HTTP Status:** 401 Unauthorized
        
        **Description:** Token not provided, invalid, or expired
        
        **Solution:** Include valid Bearer token in Authorization header
        
        ```json
        {
          "detail": "Missing credentials"
        }
        ```
      </Accordion>
    </AccordionGroup>
  </Tab>
  
  <Tab title="Validation Errors">
    Issues with request parameters.
    
    <AccordionGroup>
      <Accordion icon="text" title="Invalid Prompt">
        **HTTP Status:** 422 Validation Error
        
        **Description:** Prompt is too short, too long, or missing
        
        **Solution:** Provide prompt with 1-4000 characters
        
        ```json
        {
          "detail": [
            {
              "type": "string_too_short",
              "loc": ["body", "prompt"],
              "msg": "String should have at least 1 character"
            }
          ]
        }
        ```
      </Accordion>
      
      <Accordion icon="arrows-rotate" title="Invalid Orientation">
        **HTTP Status:** 422 Validation Error
        
        **Description:** Orientation value is not "9:16" or "16:9"
        
        **Solution:** Use valid orientation value
        
        ```json
        {
          "detail": [
            {
              "type": "enum",
              "loc": ["body", "orientation"],
              "msg": "Input should be '9:16' or '16:9'"
            }
          ]
        }
        ```
      </Accordion>
      
      <Accordion icon="clock" title="Invalid Duration">
        **HTTP Status:** 422 Validation Error
        
        **Description:** Duration is not 10 or 15
        
        **Solution:** Use 10 or 15 for duration
        
        ```json
        {
          "detail": [
            {
              "type": "enum",
              "loc": ["body", "duration"],
              "msg": "Input should be 10 or 15",
              "input": 5
            }
          ]
        }
        ```
      </Accordion>
      
      <Accordion icon="ban" title="Both Image Methods Provided">
        **HTTP Status:** 400 Bad Request
        
        **Description:** Cannot use both `image_base64` and `image_url` simultaneously
        
        **Solution:** Choose one image input method
        
        ```json
        {
          "detail": "Cannot provide both image_base64 and image_url"
        }
        ```
      </Accordion>
    </AccordionGroup>
  </Tab>

## Common Error Scenarios

### Scenario 1: Insufficient Balance

```python
# Check balance before generation
balance_response = requests.get(
    "https://platform.runblob.io/v1/data/balance",
    headers={"Authorization": f"Bearer {token}"}
)

balance = balance_response.json()["balance"]

if float(balance) < 0.12:  # Minimum for 10s video
    print("Insufficient balance. Please add credits.")
else:
    # Proceed with generation
    generate_video(prompt)
```

### Scenario 2: Invalid Image Input

```python
import base64

# Validate image before sending
def validate_image(file_path):
    # Check file size
    file_size = os.path.getsize(file_path)
    if file_size > 10 * 1024 * 1024:  # 10 MB
        raise ValueError("Image too large. Max 10MB")
    
    # Check format
    valid_formats = ['.jpg', '.jpeg', '.png', '.webp']
    if not any(file_path.lower().endswith(fmt) for fmt in valid_formats):
        raise ValueError("Invalid format. Use JPEG, PNG, or WEBP")
    
    return True

try:
    validate_image("image.jpg")
    # Proceed with generation
except ValueError as e:
    print(f"Validation error: {e}")
```

### Scenario 3: Handling Failed Generations

```python
def check_generation(generation_id):
    response = requests.get(
        f"https://platform.runblob.io/v1/sora/generations/{generation_id}/",
        headers={"Authorization": f"Bearer {token}"}
    )
    
    data = response.json()
    
    if data["status"] == "failed":
        error = data["error_message"]
        
        # Handle specific errors
        if "photorealistic people" in error:
            print("Try with a different image without people")
        elif "policy" in error:
            print("Modify your prompt to comply with policies")
        else:
            print(f"Generation failed: {error}")
        
        return None
    
    return data
```
